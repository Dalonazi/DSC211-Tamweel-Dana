# Tamweel Lite | مشروعك النهائي

## الملخص التنفيذي
تم اختيار نموذج واحد كنهج نهائي لأن النماذج التجميعية الأكثر تعقيداً
لم تحقق تحسناً كافياً يبرر التعقيد الإضافي. كما تراعي آلية اتخاذ القرار
الطاقة الاستيعابية للمراجعة، بحيث تتم مراجعة الحالات ذات الأولوية الأعلى
ضمن الموارد المتاحة. ويتطلب استخدام النموذج متابعة مستمرة للتأكد من
استقرار الأداء وجودة التنبؤات وملاءمة حجم الحالات للمراجعة مع مرور الوقت.

## Executive summary
A single model was selected as the final approach because more complex
ensemble alternatives did not provide enough additional benefit to justify
their added complexity. The final decision process also applies a review
capacity limit so that the highest-priority cases are reviewed within
available resources. Ongoing monitoring is required to ensure that model
performance, calibration and review volumes remain appropriate over time.

Decision: KEEP SINGLE / Logistic. Full-batch flags: 300/2500.
